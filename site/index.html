Your agent is the tutor

You don't read this course. An agent teaches it.

It's a course about agents, so it ships with one. Install the course skills into the coding agent you already use. It places you, writes your build plan, and walks you through each lesson in your terminal, then reviews the agent you wrote. You don't need to know the curriculum to start.

  1. 01 npx skills add Ramakm/agentic-ai-from-scratch

    Install the skills

    Nothing to clone. Works in Claude Code, Codex, Cursor, and any agent that reads SKILL.md.

  2. 02 /find-your-level

    Find your level

    Ten questions on prompts, tools, loops and evals. Your agent maps them to a starting phase, marks what you can skip, and estimates the hours.

  3. 03 /start-building

    Get your build plan

    Your goal and placement go into BUILD.md, a plan that lives in the same repo as the agent you're building.

  4. 04 /build

    Build every session

    A warm-up on the last lesson, the next one taught section by section, a code review of your agent, and your progress saved.

Agent stuck in a loop? /debug-my-agent reads your trace and links the lesson that fixes it. /check-understanding quizzes you on any phase. Commands are shown for Claude Code. In other agents, ask for the skill by name. See every skill →

How every lesson works

Most agent material comes as framework tutorials. A LangChain notebook here, a flashy multi-agent demo there, a thread about MCP somewhere else. The pieces rarely connect. You can wire a crew of five agents but can't say why the third one loops forever. You can install an MCP server but couldn't write the JSON-RPC message it answers.

This curriculum is the spine. 16 phases, 163 lessons, in Python and TypeScript. One HTTP call to a model at one end, a full agent harness with subagents, sandboxes and evals at the other. Every pattern gets built by hand first: the tool dispatcher, the ReAct loop, the vector store, the MCP server, the orchestrator. When the frameworks show up, you already know what they do.
